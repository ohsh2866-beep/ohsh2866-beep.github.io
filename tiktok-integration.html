TikTok integration

How Trend Radar Daily uses the TikTok Content Posting API and Login Kit.

What we use, and why

Product / scopeHow this service uses it
Login Kit
user.info.basic		 The operator signs in with the TikTok account that owns each of our two channels, so the service knows which authorized account a video belongs to. We read only the basic profile (open id, display name) to confirm the correct account is connected. No other user data is read.
Content Posting API
video.upload		 After the daily video is produced, the file is uploaded to the authorized account's TikTok inbox as a draft. The operator opens TikTok, reviews the draft, and posts it. Nothing is published without that human step.

End-to-end flow

  1. The operator authorizes our TikTok account through Login Kit. The access token is stored locally on the operator's own machine and is never shared.
  2. The daily pipeline produces a vertical video - the same file that goes to YouTube Shorts.
  3. The service calls the Content Posting API to send that file to the authorized account's inbox as a draft, using the video.upload scope.
  4. The operator opens the TikTok app, reviews the draft, adds or edits the caption, and posts it.

We request video.upload only, not direct posting. Every video passes through a human review step inside the TikTok app before it reaches an audience.

Scope of use

  • Videos are uploaded only to the two TikTok accounts we own and operate.
  • The service has no other users. It is a single-operator tool, not a platform offering posting on behalf of others.
  • No TikTok data is stored beyond the access token and the account's open id, both kept locally.
  • Videos are the same AI-assisted news briefings published on our YouTube and Instagram channels, labeled as AI-generated.
